# Amazon Brazil E-Commerce Analytics
### E-Commerce Data Analysis Using SQL

**Author:** Garima Yadav

## Project Overview

This project focuses on analysing Brazilian e-commerce data using SQL to identify business insights related to sales performance, customer behaviour, seller performance, product categories, payment methods and delivery operations.

The analysis uses the publicly available Olist Brazilian E-Commerce Dataset to explore an Amazon Brazil-style e-commerce business case study.

## Objectives

- Analyse order distribution across seller locations.
- Identify top-performing product categories.
- Understand customer purchasing and spending patterns.
- Examine payment methods and average order value.
- Evaluate seller performance.
- Analyse customer review scores.
- Investigate delivery timelines and monthly order trends.

## Tools & Technologies

- SQL (MySQL)
- Data Analysis

## Dataset

The project uses the Olist Brazilian E-Commerce Dataset, containing information about customers, orders, products, sellers, payments, reviews and other e-commerce operations.

The repository includes a data dictionary explaining the dataset tables and their structure.

## SQL Analysis

The project includes 14 SQL queries addressing business questions such as:

1. Order distribution by seller state.
2. Cumulative revenue by product category.
3. Payment methods and average order value.
4. Highest-spending customer.
5. Average review scores by product category.
6. Customer order distribution by state.
7. Identification of inactive sellers.
8. Top five revenue-generating categories.
9. Median delivery time.
10. Products that have not been ordered.
11. Above-average seller revenue.
12. Review scores across states.
13. Customers who have not submitted reviews.
14. Monthly order trends.

## Key Business Insights

- São Paulo accounted for approximately 71% of the orders analysed.
- Health & Beauty generated approximately R$1.26 million in revenue.
- Credit cards represented approximately 75% of orders.
- The highest-spending customer recorded purchases worth approximately R$13,664.08.
- Median delivery time was approximately 10 days.
- August recorded 10,843 orders in the monthly analysis.
